为搜狗输入法小米版补全并统一 Unicode Emoji 的 LSPosed 模块。

> **源码仓库：** https://github.com/250king/SougouEmojiFixer

搜狗自带表情包的 Unicode 覆盖不全、风格不统一（符号、旗帜等用系统字体），本模块用完整且风格统一的 **Noto Emoji** 替换搜狗的表情分组，并支持对表情分组进行排序管理。
